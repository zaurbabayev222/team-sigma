# Embedded display typeface

IBM Plex Sans Medium, from [IBM's official Plex repository](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/woff2).
Original file: `IBMPlexSans-Medium.woff2`. Downloaded 22 October 2026, unmodified.
The accompanying [LICENSE.txt](LICENSE.txt) is IBM's supplied license. The font and license are embedded
in the generated HTML so the single-file presentation works offline and carries its attribution.
Body text keeps the platform sans stack; display headings use the embedded Plex font.
